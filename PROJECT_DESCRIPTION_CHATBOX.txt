📱 PROJECT OVERVIEW

Focus is a full-stack social media application built with React and Supabase, featuring Instagram-level functionality with real-time capabilities. It's a production-ready platform with 40+ features, 2,700+ files, and 122,000+ lines of code.

🔐 AUTHENTICATION & PROFILES
• Secure email/password authentication with JWT tokens
• Customizable user profiles with bio, avatar, cover photo
• Public/private account settings
• Profile verification badges (Trust Shield)

• Two-factor authentication support

• Draft system for saving posts

• Skeleton loaders for smooth UX
