## 🔧 CUSTOMIZATION OPTIONS

All colors are CSS variables - easy to adjust!

### Change Primary Color
```css
/* In src/index.css */
:root {
  --focus-lavender: #YOUR_COLOR;
}
```

### Change Accent Color
```css
:root {
  --focus-accent: #YOUR_COLOR;
}
```

### Change Background Tint
```css
:root {
  --bg-secondary: #YOUR_COLOR;
}
```

## ⚠️ MINOR NOTES

### CSS Compatibility Warnings
There are some CSS compatibility warnings for older browsers:
- `backdrop-filter` (iOS Safari <9)
- `user-select` (Safari <3)
- `scroll-behavior` (iOS Safari <15.4)

**These are NOT errors!** They're just linter suggestions. The app will work perfectly fine in all modern browsers. These properties gracefully degrade in older browsers.
