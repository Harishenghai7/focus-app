# 🦁 Focusly AI - Quick Start Guide

## ⚡ 3-Minute Setup

### Step 1: Get Gemini API Key (1 minute)
1. Visit https://makersuite.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key

### Step 2: Configure Environment (30 seconds)
1. Open `.env` file in project root (create if doesn't exist)
2. Add this line:
   ```
   REACT_APP_GEMINI_API_KEY=paste_your_key_here
   ```
3. Save the file

### Step 3: Start the App (30 seconds)
```bash
npm start
```

### Step 4: Meet Focusly! (1 minute)
1. Look for the floating purple button (bottom-right)
2. Click it OR press `Ctrl + Shift + F`
3. Say hello! 👋

## 🎮 Quick Tips

**Voice Input:**
- Click the microphone 🎤 icon
- Speak your message
- Works best in Chrome/Edge

**Voice Output:**
- Focusly speaks all responses by default
- Toggle with speaker 🔊 icon

**Move Focusly:**
- Drag the avatar anywhere on screen
- Position saves automatically

**Keyboard Shortcut:**
- `Ctrl + Shift + F` - Open/close chat

## 🐛 Troubleshooting

**"I need a Gemini API key"**
→ Add `REACT_APP_GEMINI_API_KEY` to `.env` and restart server

**Voice not working**
→ Check speaker icon is enabled (not muted)

**Microphone not working**
→ Use Chrome/Edge browser and grant microphone permission
