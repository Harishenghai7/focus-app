╔═══════════════════════════════════════════════════════════════════════════╗
║                          HOW TO USE                                       ║
╚═══════════════════════════════════════════════════════════════════════════╝

1. Verify your .env file contains:
   REACT_APP_GEMINI_API_KEY=your_actual_api_key_here

2. Start your development server:
   npm start

3. Navigate to Focusly AI:
   http://localhost:3000/focusly

4. Start chatting:
   • Type a message and press Enter
   • Click quick action buttons
   • Toggle voice on/off as needed
   • Watch Focusly's animated reactions!

5. Test different emotions:
   • "Hello!" → Happy 😄
   • "Help me" → Thinking 🤔
   • "Amazing!" → Excited 🎉
   • "Thank you" → Happy 💜
