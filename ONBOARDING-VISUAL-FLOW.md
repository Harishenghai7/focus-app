                              ERROR HANDLING

    Step                Possible Errors              User Feedback
    ────                ───────────────              ─────────────
    
    OAuth               • Provider unavailable       Red alert box
                        • Network error              "Unable to connect..."
                        • User cancelled             
    
    Phone               • Already registered         Red alert box
                        • Invalid format             "Phone already in use"
                        • Network error              Form field highlight
    
    OTP                 • Invalid code               Red alert box
                        • Expired code               "Invalid verification"
                        • Too many attempts          Retry option
    
    Username            • Already taken              Red text + X icon
                        • Too short                  "Username is taken"
                        • Invalid chars              Real-time feedback
    
    Profile Pic         • File too large             Red alert box
                        • Invalid format             "Max 5MB"
                        • Upload failed              Retry option

                              SECURITY FEATURES

    Feature                    Implementation           Purpose
    ───────                    ──────────────          ───────
    
    OAuth                      Supabase built-in       Trusted auth providers
    Phone Verification         One phone = one user    Prevent fake accounts
    Username Uniqueness        DB constraint           One identity per user
    File Size Limit            Client validation       Prevent abuse
    OTP Expiration            Session-based           Security timeout
    Back Button               State preservation       User control
    Input Sanitization        Regex validation        Prevent injection
    Loading States            UI feedback             Prevent double-submit
