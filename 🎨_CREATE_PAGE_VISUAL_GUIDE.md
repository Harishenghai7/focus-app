## 🎯 VALIDATION RULES

### File Upload
- **Max files**: Post (10), Boltz (1), Flash (1)
- **Max size**: 100MB per file
- **Allowed types**: 
  - Images: JPG, PNG, GIF, WebP
  - Videos: MP4, QuickTime, WebM
- **Boltz**: Video only

### Caption
- **Max length**: 
  - Post/Flash: 2200 chars
  - Boltz: 150 chars
- **Supports**: Emoji, @mentions, #hashtags

### Schedule
- Must be future date/time
- Cannot schedule more than 6 months ahead

### Music (Boltz)
- Required for Boltz
- Optional for Posts with video
- Not available for Flash

## 🚀 PERFORMANCE TIPS

### Image Optimization
- Compress before upload (80% quality)
- Resize to max 1920px
- Generate thumbnails for grid

### Video Optimization
- Compress to H.264
- Max bitrate: 8Mbps
- Generate poster frame
- Create preview thumbnail

### Code Optimization
- Lazy load components
- Debounce autosave (10s)
- Clean up object URLs
- Memoize expensive operations
