🔑 SETUP
────────────────────────────────────────────────────────────────────────────

2. Run: npm start
3. Navigate to /focusly
4. Start chatting!

Issue: No voice
Fix:   Enable audio in browser, toggle voice button

Issue: Route not found
Fix:   Restart dev server (npm start)
